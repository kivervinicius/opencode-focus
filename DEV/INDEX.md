# Index da Documentação DEV — opencode-focus

Este repositório utiliza a estrutura `DEV/` para documentação durável do projeto.

## Arquivos Principais

- `DEV/INDEX.md`: Este índice.
- `DEV/CONTEXT.md`: Contexto arquitetural e visão geral do projeto.
- `DEV/SPECS/ACTIVE.md`: Especificação ativa do recurso atual (Suporte a Zellij).
- `DEV/HANDOFF.md`: Resumo de estado para a próxima interação/agente.
- `DEV/VERIFY.md`: Plano de testes e resultado das verificações.
- `DEV/WORKLOG.md`: Histórico de trabalho realizado.
